Slowsky lets anyone pick a star and watch the sky change, by blinking real NASA SPHEREx pictures of the same spot taken months apart. Try it: slowsky.clupai.com

AI disclosure:
- Images: the painted backgrounds and elements were made with OpenAI GPT Image (model gpt-image-2). They are decoration only, never data.
- Voice: the narration is an AI voice, not a person: ElevenLabs, library voice "Adam Stone (Smooth, Deep and Relaxed)", model eleven_multilingual_v2.
- Sound: the sound effects and the music bed are synthesised in code (numpy), not recorded and not made by an AI audio model. The code was written with Claude Opus 5.5.
- Script and code: the narration words and the film's animation code were written with Claude (Anthropic); parts of the code were reviewed with Codex (OpenAI).
- What each AI tool made, with the prompts: https://github.com/Clupai8o0/slowsky/blob/main/SOURCES.md#ai-generated-content

The sky pictures are real NASA SPHEREx data.
Data: NASA SPHEREx via IRSA (NASA/IPAC). Gaia: ESA/Gaia/DPAC.
