## Name (2-4 words)
Sky First Workspace

## Core idea (one sentence)
Open directly on one understandable sky comparison, with every explanation and control arranged around that observation.

## First 10 seconds (what the visitor sees and does, step by step)
1. See “Watch the infrared sky change,” Barnard’s Star selected, and the real image immediately.
2. Read one instruction above it: “Watch the marked star between visits.”
3. Press the prominent “Play visits” button; the date changes alongside the frame.
4. Read the nearby caveat: “Its bright centre makes the measured position approximate.”
5. Choose “Change target” or explore another infrared colour.

## Desktop layout (regions, what lives where)
A compact header holds the striped logo, sharing and appearance controls.

The workspace has two columns: a dominant viewer and a 300px explanation panel. Above the viewer: target selector, saved/live status and fullscreen. Below: playback, dated thumbnails, comparison modes and colour.

The explanation panel combines “What to look for,” limitations and candidate changes. At 768px it moves below the viewer; no third column at any width.

## Phone layout
Target selector, one instruction, sky, playback, dates, colour, explanation—in that order. At 320px, thumbnails scroll horizontally and controls wrap into labelled rows. Target selection opens a searchable sheet containing all five examples and coordinate search.

## What you hide or cut (and where it goes instead)
Cut the permanently expanded target catalogue and repeated explanations.

“Display options” holds overlays and field size. “Frame details” holds coordinates, diagrams, detector, release, scale, file, measurements and FITS download. Keep consequential limitations visible beside the observation.

## Controls (how blink / stack / subtract, frame stepping, colour and the overlays work; no pills)
Underlined Blink / Stack / Subtract tabs include short explanations. Previous, Play/Pause and Next remain beside dated frame selection. Colour uses a labelled wavelength slider with explicit loading feedback. Overlays use square checkboxes; only the target marker starts enabled. Use 44px touch targets, visible focus and keyboard operation; announce manual frame changes without narrating playback.

## Light and dark (how the dark sky image sits in a light UI)
White surfaces, graphite Geist text, blue actions; Geist Mono only for values. The unchanged dark image sits inside a charcoal frame. Dark mode changes surrounding surfaces, never data rendering. All corners stay within 4px.

## Riskiest assumption
One preselected example can teach the interaction before visitors need the full target catalogue.
